# E-Commerce-Return-Analysis-Dashboard

This project is an E-Commerce Return Analysis Dashboard created to understand product returns and the reasons behind them.

The main aim of the project is to use data to identify return patterns, understand the major reasons customers return products, and look at the cost associated with product returns. I used Power BI to analyze the data and create an interactive dashboard that presents the findings in a simple and easy-to-understand way.

## Project Objective

The objectives of this project are to:

- Analyze e-commerce return patterns.
- Identify the major reasons for product returns.
- Find product categories with high return activity.
- Analyze return costs.
- Understand customer return patterns.
- Provide insights that can help reduce unnecessary returns and improve business decisions.

## Dataset

The dataset contains information about e-commerce orders, products, customers and returns.

Some of the fields in the dataset include:

- Order ID
- Order Date
- Order Quantity
- Order Value
- Product Category
- Product ID
- Product Price
- Return Status
- Return Reason
- Days to Return
- Return Cost
- Payment Method
- Shipping Method
- Customer Age
- Customer Gender
- User Location
- Discount Applied
- Packaging Method
- Packaging Waste
- CO₂ Emissions
- CO₂ Saved
- Waste Avoided

## Data Preparation

Before creating the dashboard, I prepared the dataset for analysis. I checked the data, worked on the data types and cleaned and transformed the information where necessary.

I also created the required calculations and measures to help me analyze the return data and present meaningful insights in the dashboard.

## Tools Used

- Microsoft Power BI – Data analysis and dashboard development
- Power Query – Data cleaning and transformation
- DAX – Creating measures and calculations
- CSV – Dataset

## Dashboard

The dashboard provides an overview of e-commerce returns using KPIs, charts and interactive visuals.

It covers areas such as:

- Return performance
- Return rate
- Return costs
- Return reasons
- Product categories
- Customer age-groups
- Days to return

The dashboard allows users to interact with the data and look at different aspects of product returns.

## Business Problem

E-commerce businesses can experience a high number of product returns without having a clear understanding of why customers are returning their products.

This can lead to additional costs and waste and can also affect customer satisfaction.

This project helps address this problem by analyzing return data and identifying patterns that can help the business understand where improvements may be needed.

## Target Users

The dashboard can be useful to:

- E-commerce business owners
- Business managers
- Sales and operations teams
- Customer service teams
- Data analysts

These users can use the dashboard to understand return patterns and support better business decisions.

## SDG Contribution

This project contributes to SDG 12 – Responsible Consumption and Production.

By analyzing product returns and factors such as packaging waste, CO₂ emissions, CO₂ saved and waste avoided, the project can help businesses identify opportunities to reduce unnecessary returns and waste and make more responsible decisions.

## Expected Impact

I expect this project to help e-commerce businesses better understand their return patterns and the reasons behind them.

The insights can help businesses identify areas with high returns, reduce unnecessary return costs, improve their processes and ultimately improve customer satisfaction.
